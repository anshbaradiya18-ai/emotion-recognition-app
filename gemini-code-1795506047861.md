## Overview
A real-time web application that detects human faces via browser webcam input (`OpenCV` Haar Cascade + Histogram Equalization) and classifies facial expressions into 7 emotion classes (`Happy`, `Sad`, `Angry`, `Surprised`, `Disgust`, `Fear`, `Neutral`) through a `FastAPI` backend and live analytics dashboard.
